# v8 Forward Shadow Output Area

This directory is reserved for future paper-tracking outputs generated by
`research/v8_research/forward_shadow_runner.py`.

The runner is paper-only. It does not place orders and must not be connected to
any broker or auto-trading system.

Expected daily outputs:

- `daily_signals/YYYYMMDD_signals.csv`
- `daily_ledgers/YYYYMMDD_ledgers.csv`
- `daily_execution_quality/YYYYMMDD_execution_quality.csv`

Expected cumulative outputs:

- `forward_shadow_daily_summary.csv`
- `forward_shadow_trade_details.csv`
- `forward_shadow_no_trade_days.csv`
- `forward_shadow_execution_quality.csv`
- `forward_shadow_candidate_status.csv`

The schema is documented in
`reports/tushare/v8_research/forward_shadow_setup/forward_shadow_schema.csv`.
